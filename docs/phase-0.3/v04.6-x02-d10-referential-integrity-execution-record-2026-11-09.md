## 4. Concurrent parent-mutation / child-insert verification

Two deliberately ordered concurrency schedules were run on each target. Each schedule used separate sessions and a four-second parent/child transaction hold to force the competing statement to wait on the relevant FK lock. The observed competing statement duration was approximately 3.45–3.48 seconds in each case, consistent with the intended wait.

### Scenario 1 — parent update first, parent transaction rolls back

1. Create two Organizations and a Company referencing the first Organization.
2. Start a transaction that updates the Company’s organizationId to the second Organization and holds the transaction open for four seconds.
3. Start the Plant insert referencing the original Organization/Company tuple while the parent update is uncommitted.
4. The Plant insert waits for the parent transaction, then succeeds after the parent transaction rolls back.

**Observed:** child insert succeeded after parent transaction rollback on both fresh and staged targets.

### Scenario 2 — child insert first, child transaction commits

1. Create two Organizations and a Company referencing the first Organization.
2. Start a transaction inserting a Plant with the matching original Organization/Company tuple and hold it open for four seconds.
3. Start a parent Company organizationId update while the Plant insert is uncommitted.
4. The parent update waits for the child transaction, then is rejected after the child commits.

**Observed:** parent key update was rejected with SQLSTATE 23503 on both fresh and staged targets.

| Concurrency outcome | Fresh | Staged |
|---|---|---|
| Parent update starts first and rolls back; waiting Plant insert succeeds | PASS | PASS |
| Plant insert starts first and commits; waiting parent update fails with SQLSTATE 23503 | PASS | PASS |
| Both schedules preserve the same-Organization invariant | PASS | PASS |

The user-provided terminal output showed the expected wait durations, both scenario outcomes, and final invariant checks on each target.
